Accessibility

Accessibility

The app is designed to work with standard accessibility features on iPhone, iPad, and Mac.

Implemented accommodations

  • Spoken labels or summaries for primary buttons, event rows, the timeline, maps, ground views, and graphs
  • Adaptive vertical layouts for timeline controls and explanations at large text sizes
  • Support for the system Light and Dark appearances
  • Solid, dashed, and dotted map lines and legends so important information is not identified by color alone
  • Display behavior that responds to Differentiate Without Color and Reduce Motion settings
  • Alternative summaries for the eclipse canvas, including the selected location, eclipse state, and model cautions

Current limitations

Maps and sky views contain dense visual information. Rather than exposing every map line or star as a separate item, spoken access provides a summary of the selected event and observing location. Graphs similarly focus on a spoken summary of their values.

Feedback

For an issue involving VoiceOver, Voice Control, text size, contrast, color differentiation, or motion, use the support page.
